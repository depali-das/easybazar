# 🛒 EasyBazar – Fresh Daily

### সহজ বাজার, ঘরে ঘরে। 🥬

**EasyBazar** is a modern, responsive online grocery shopping platform designed for customers in Rajshahi, Bangladesh. Shop for fresh vegetables, fish, meat, rice, lentils, cooking oil, eggs, groceries, beverages, and personal care products from the comfort of your home.

**GitHub Repository:** [depali-das/easybazar](https://github.com/depali-das/easybazar)

---

- 🥬 Fresh Vegetables, Fruits, Fish & Meat

- ⚡ Flash Sales & Special Offers

## 🔍 Smart Search System

EasyBazar includes a browser-based smart search experience.

- Search products using Bangla or English.
- Instant product filtering while typing.
- Bangla/English keyword mapping.
- Fuzzy matching for better search results.
- Product details open directly from search suggestions.
- Add products to cart from search results.
- Keyboard navigation using Enter and Escape.
- Recent search history (up to 10 items).
- Clear search history option.
- Trending search tracking.

**LocalStorage Keys:**
- `easybazar_search_history`
- `easybazar_trending_searches`

## 🛍️ Product Catalog

- Category filtering
- Minimum and maximum price filtering
- Recently added products
- Discounted products
- Clear filters when no products match

All search and catalog filtering features work directly in the browser without requiring a backend API.

## 💻 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/depali-das/easybazar.git
```

**2. Open the project folder**

```bash
cd easybazar
```

**3. Install dependencies**

```bash
npm install
```

**4. Start development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

**5. Build for production**

```bash
npm run build
```
