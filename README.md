### Smart Search ব্যবহার
Storefront-er header search-e Bangla ba English e product search kora jay. Type korar songe songe catalog result filter hoy, nirbachon korle product details khulbe, ar cart icon diye sorasori add kora jay. Enter ebong Escape diye dropdown chalano jay.

Samprotik search sorboccho 10ti hisebe `easybazar_search_history` ebong `easybazar_trending_searches` -e rakha hoy. Dropdown-e Clear, Bangla/English keyword mapping ebong fuzzy matching ache.

Catalog-er filter theke category, min/max price, recently added, discounted product filter kora jay. Match na thakle clear-filter action dekhay. Eta sompurno browser-e kaj kore, kono backend babohar kore na.
